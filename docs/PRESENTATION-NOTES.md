# Presentation Notes — Demo Script for Hospital Doctors

**Purpose:** Winning trust and an MoU from Sree SS Yashoda Hospital's doctors and management.

---

## Opening (1 min)

> "This is a production-grade website built specifically for Sree SS Yashoda Hospital in Anantapur — not a template. Everything you see is real, verified content about your hospital."

- Open the site on a large screen or projected display
- Let the homepage load — the **interactive logo watermark** behind the hero is the first wow moment
- Point out: "Notice how the hospital's own logo is subtly woven into the background as a pattern — and it reacts to where your cursor moves."

---

## Section-by-Section Walk (8–10 min)

### 1. Hero Section
- Show the **real hospital exterior photo** on the right
- Point to the **three floating info cards** (52 beds, Old Town location, call/book actions)
- Show the "Book an Appointment" button — explain it leads to a working form

### 2. Trust Strip
- Show the 4 verified stats: **52 beds, 9 areas of care, location, specialist consultations**
- Explain: "We only show facts we could verify. No inflated numbers."

### 3. Doctors
- Show **Dr. B. Siva Sankar Naik** and **Dr. R. Swetha** cards
- Hover over a card — the photo scales, credentials reveal
- Click "Book with Dr. X" — shows how the form pre-fills the doctor's name

### 4. Specialities
- Click through the left list — description + tags crossfade on the right
- On mobile, show the accordion version

### 5. Appointment Form
- Fill in a test request (any name, 9876543210, choose a speciality)
- Submit — shows "Request Received" confirmation
- Explain: "Currently set to test mode. Switch to WhatsApp mode to instantly route requests to your phone."

### 6. Contact & Map
- Show the address card with call button
- Click "Load Map" — map loads only when the user clicks (privacy-friendly)
- "Get Directions" opens Google Maps

---

## Technical Credibility Points (2 min)

- **Zero made-up stats** — every number shown is verified (52 beds from AP Pollution Control Board records)
- **Built to be updated** — all content lives in text files, not scattered in code. A staff member can update doctor info or add a new doctor without any technical knowledge
- **Phone-optimised** — show on a mobile device: sticky call bar, large tap targets, fast load
- **Works offline** — PWA installed version works without internet

---

## The MoU Opportunity — What We Can Add (3 min)

The current website is a **Phase 1 marketing layer**. A software MoU unlocks Phase 2:

| Feature | Benefit |
|---|---|
| **Patient Portal** | Patients view appointment history, reports, invoices |
| **Online Booking with Real Slots** | No phone tag — doctor calendars connected, slots confirmed instantly |
| **EMR/HMS Integration** | Patient records, billing, pharmacy linked to the website |
| **WhatsApp Reminders** | Automated appointment reminders via WhatsApp Business API |
| **Analytics Dashboard** | See which specialities get most enquiries, call conversion rate |
| **OPD Queue Display** | Live token display on a screen at reception |

> "The website you see today is the front door. The MoU is about building the entire patient management system behind it."
